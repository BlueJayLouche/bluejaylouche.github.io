Software

Open source, mostly Rust. All of it is on GitHub.

CuePool

A cue player for live shows. Sound, video and lighting cues run from one list, with projection mapping, DMX over sACN and Art-Net, and OSC, MIDI and timecode for show control. I build it with scroix, and it runs the Longreach gallery listed below.

  • Rust
  • show control
  • macOS · Windows · Linux
User guide Source

KOVVBOJ

A layer-based VJ app. Stack video, cameras and ISF shaders, crossfade between two decks, map the result onto surfaces, and send it to projectors, LED strips and lasers. Built on rustjay-engine.

  • Rust
  • VJ
  • macOS · Windows · Linux
Download Source

rustjay-engine

A VJ engine in Rust: for live visuals what Bevy is for games. It handles GPU rendering, video in and out (NDI, Syphon, Spout, DeckLink), audio analysis, tempo sync with Ableton Link and Pro DJ Link, MIDI and OSC, projection mapping and DMX output, so an app only has to bring the shader and the idea. KOVVBOJ is built on it.

  • Rust
  • wgpu
  • NDI
  • sACN · Art-Net
  • ISF shaders
Guide Source

stageLX

A real-time 3D stage lighting visualiser and DMX controller. Imports GDTF fixtures and MVR scenes, and outputs Art-Net and sACN.

  • Rust
  • Bevy
  • DMX

rustjay-mapper

A lightweight projection mapping tool with NDI and Syphon in and out, and video wall calibration from AprilTags.

  • Rust
  • mapping

hap-rs

Rust crates for the HAP video codec: encode, decode and GPU playback, with no FFmpeg needed to encode.

  • Rust
  • video

Aroma_link

An ESP32 that fires scent diffusers on cue from a lighting desk. sACN or OSC in, Bluetooth out, with failsafes that turn the scent off if the network drops.

  • C++
  • ESP32
  • sACN

maschine-mk1

Rescue firmware for the original Native Instruments Maschine Mk1. Turns an abandoned controller into a standalone wireless OSC and MIDI surface.

  • ESP32

Printable covers for obsolete media: VHS slip boxes, clamshell wraps and cassette J-cards.

About

I'm an AV technician and technical designer in Melbourne. I spent ten years at Museums Victoria, starting as a technician running the galleries day to day and finishing as Senior Technician, building infrastructure and control systems and taking the on-call faults.

Since 2022 I've worked on contract and freelance: festival installs, a permanent gallery, and sound design for film and exhibitions. BlueJayLouche is the name I publish software under.
