# bluejaylouche.github.io

Personal site for Andrew Cherry (BlueJayLouche): <https://bluejaylouche.github.io/>

One static `index.html` with inline CSS. No build step, no JavaScript and no third-party requests. Screenshots live in `assets/`.

Preview locally:

```sh
python3 -m http.server 8000
```

GitHub Pages serves the `main` branch, so a push to `main` publishes.
